# 卡牌對戰｜多人連線版

本專案將 `CardBattle_updated_v5.html` 改為由伺服器管理的雙人連線版本。

## 本機啟動

1. 安裝 Node.js 20 或更新版本。
2. 在此資料夾開啟終端機。
3. 執行：

Windows PowerShell：

```powershell
npm.cmd install
npm.cmd start
```

macOS / Linux：

```bash
npm install
npm start
```

4. 開啟 `http://localhost:3000`。
5. 玩家 A 建立房間，玩家 B 輸入六位房間代碼加入。兩位玩家各自準備後，由房主開始。
6. 若要跨網路遊玩，需將整個專案部署到支援 Node.js、WebSocket 的主機，並將網址分享給朋友。

## 已接上的多人功能

- 兩人房間、六位代碼、準備與房主開始。
- 每位玩家送出自己的 60 張牌組；伺服器驗證總數必須剛好 60 張。
- 伺服器保存牌庫、手牌、棄牌區、生命值、附魔與控制狀態。
- 每輪開始雙方各抽最多 10 張；牌庫不足時會洗回棄牌區補牌。
- 雙方都能看到彼此手牌；行動位置在雙方提交前不會公開。
- 雙方提交後由伺服器逐位置結算；客戶端不能自行回報傷害或勝負。
- 五個行動位置、屬性盾、閃避、防禦、治療、破甲、禁錮、淨化、基礎劍招及三種附魔、鋒利。
- 本輪結束後雙方都確認，才進入下一輪。

## 目前限制與規則說明

- 伺服器使用記憶體保存房間；伺服器重啟會清除進行中的房間。
- 玩家重新整理後可用同一瀏覽器的保存 token 加入原房間，但目前沒有斷線保留期限或跨裝置恢復。
- 本版依照 v5 HTML 中實際存在的 12 張基礎卡牌移植。善惡一、時序一等擴充規則不在這份 HTML 的卡牌資料中，因此沒有擅自加入。
- 雷電附魔的打斷效果在 v5 文字中提到，但目前沒有蓄力狀態可供打斷，故本版不會產生額外打斷效果。
- 屬性盾在本版以火焰、水、雷電屬性判斷；基礎劍招和附魔傷害依伺服器結算。
- 目前是可測試的多人版本，尚未完成完整瀏覽器自動化測試及正式公開部署。

## 部署

可部署到 Render、Railway 等支援 Node.js Web Service 與 WebSocket 的平台。使用 `npm start` 啟動，平台會透過 `PORT` 環境變數指定連接埠。請使用 HTTPS 公開網址。
